# AI作品集网站项目记忆文件｜欧睿 × Luxury Editorial

## 1. 项目目标

用户正在制作一个用于求职的个人设计作品集网站，定位不是程序员作品集，也不是纯 AI 生成作品展示，而是：

> AI视觉设计师 / 电商视觉设计师 / 品牌视觉设计师

核心目标：
- 展示真实商业项目经验，尤其是欧莱雅 Luxe / 植村秀实习期间产出的作品。
- 展示 AI 创作、LoRA、AI 工作流能力。
- 展示 3D 建模、产品渲染能力。
- 网站本身也成为用户“设计 + AI工具应用能力”的证明。
- 网站需要有高级感，但不能像建筑事务所、艺术策展机构、SaaS/科技公司官网。
- HR 打开网站后应该快速理解：这个人是谁、做过什么、有什么商业设计能力、AI 能力和视觉能力。

## 2. 已确定的网站视觉方向

最终倾向：

### Luxury Editorial + 磨砂 / 哑光质感

关键词：
- Luxury Editorial
- Dark Minimalism
- Matte Texture
- Frosted Glass
- Premium Beauty Campaign
- Fashion Magazine Layout
- Editorial Storytelling
- Cinematic Lighting
- High-end Beauty
- Quiet / Sophisticated / Premium

参考气质：
- Aesop：克制、留白、品牌感
- Apple：大图、大标题、清晰的信息层级
- 高端时尚 / Editorial：杂志排版、艺术指导、图片叙事
- Acne Studios / COS / Gentle Monster / Rimowa：作为额外视觉参考

注意：
- “Aesop 30% + Apple 30% + High-end Fashion 40%”只是风格构成比喻，不是必须严格执行的设计比例。
- 磨砂质感主要作为层次和材质语言，而不是让整个网站都变成毛玻璃 UI。
- 避免过度 Glassmorphism。
- 避免霓虹、蓝紫科技感、SaaS Dashboard、建筑事务所官网、纯艺术展览网站、Behance 九宫格。
- 黑色不是唯一重点，真正重点是“高级杂志编辑感 + 商业美妆视觉 + 克制的材质层次”。

## 4. 已确定的网站信息架构

用户最终确定的结构是：

1. 首页
2. 关于我
3. 项目作品
4. AI实验室
5. 建模渲染
6. 联系方式

重要说明：
- 顶部导航栏是“目录”，不是要求把作品优先于关于我。
- 用户明确希望页面滚动顺序和导航顺序一致。
- 用户希望“关于我”先于“项目作品”出现。
- “项目作品”是一个大板块，可以内部包含“精选案例”和“更多项目”。
- 不要把“精选案例”和“更多项目”强行拆成两个一级导航。
- “关于我”希望做成较大的完整屏幕板块，接近 1920×1080 的视觉感，而不是小卡片。

最终导航建议：
首页 → 关于我 → 项目作品 → AI实验室 → 建模渲染 → 联系方式

## 5. 各板块设计要求

### 01 首页 Hero

目标：第一眼让人知道这是“欧睿的 AI视觉设计师作品集”，而不是建筑或咨询网站。

建议：
- 100vh
- 大幅视觉作为核心
- 左侧或左下方大标题
- 右侧 / 背景使用一张高质量品牌、产品、3D 或 AI视觉作品
- 图片要有电影感、哑光、高端美妆广告感
- 轻微滚动视差
- 首屏不要塞太多文字

建议中文信息：
欧睿
AI视觉设计师
品牌视觉 × 电商设计 × AI创意生产

可选辅助：
精选作品
2024—2026

### 02 关于我

用户明确希望这个板块“大一点”，约一个 1920×1080 的完整视觉区。

不要做成几个小卡片拼起来。

推荐：
- 全屏 / 接近 100vh
- 大标题“关于我”
- 简洁个人介绍
- 黑色 / 深灰磨砂材质背景
- 大型半透明磨砂面板可以有，但不要过度
- 可以加入个人照片 / 黑白肖像
- 可以加入几个关键数据，但数据必须真实，不要为了视觉效果虚构

可以考虑的信息：
- 设计背景：环境设计专业转向电商 / 品牌视觉
- 商业经历：欧莱雅 Luxe / 植村秀相关实习与商业视觉项目
- 能力方向：品牌视觉、电商视觉、AI创意生产、3D建模渲染
- AI：LoRA、生成式视觉、AI辅助工作流

注意：过去 Prompt 中曾举例“20+项目、500+ AI生成素材、3+ LoRA、2+品牌”，这些只是占位示例，除非用户确认真实数据，否则 Agent 不应该直接使用。

### 03 项目作品

这是整个网站最重要的板块之一，建议占网站总内容约 40%～50%。

不要用普通 Behance 式九宫格。

建议采用“高级杂志案例叙事”。

一级标题：
项目作品

内部：
A. 精选案例
B. 更多项目

精选案例：
- 3 个最强商业案例
- 每个案例可以接近一屏
- 大图 + 少量文字
- 点击进入完整 Case Study

案例详情建议结构：
1. 项目背景
2. 我的职责
3. 设计挑战
4. 视觉策略
5. 视觉探索 / 过程
6. 最终成果
7. 延展应用
8. 项目总结

图片排版建议：
- 第一屏：一张超大 Hero / KV
- 第二屏：2～3 张探索图，左右或错位排版
- 第三屏：最终视觉大图
- 第四屏：电商 / 社媒 / Banner 等延展应用，可横向组合
- 图片尽量大，避免大量小卡片
- 图片是构图核心，而不是装饰

用户目前需要更新作品集图片，因此图片内容后续会替换。

项目内容可围绕用户真实经历组织：
品牌视觉：
- 植村秀琥珀油春季 KV / 延展
- 植村秀季节视觉延展
- 其他真实品牌视觉项目

电商视觉：
- 欧莱雅相关电商主图
- 活动视觉
- 品专 / 详情页
- 工单美图等真实商业输出

注意：具体项目名称和成果必须以用户实际素材为准，不要虚构。

### 04 AI实验室

与商业项目分开，突出“AI不是只会生成图片”。

内容方向：
- LoRA 训练
- AI 工作流
- 生成式视觉实验
- AI 创作比赛
- Prompt / 工作流研究
- AI 辅助电商视觉生产

风格：
- 艺术实验室
- 视觉研究
- Editorial
- 不要做成科技公司 Dashboard
- 不要满屏代码和蓝色科技 UI

可以展示：
原始素材 → AI探索 → 筛选 → 后期 → 最终视觉

重点体现“设计判断”而不是“Prompt 很长”。

### 05 建模渲染

这是用户希望单独保留的差异化能力。

内容：
- Blender / Cinema 4D（以用户实际软件为准）
- 产品建模
- 产品渲染
- 材质研究
- 光影探索
- 3D视觉

排版：
- 大图
- Gallery / Editorial
- 一张主视觉 + 多张细节
- 产品像高端商业摄影一样展示
- 文字少
- 重点突出材质、光线、建模精度

## 6. 文案方向

用户不喜欢：
- 全英文网站
- AI自动生成的“文艺但空泛”的中文
- 类似“策展之物”这种为了高级而高级的词

用户更倾向：
- 简洁
- 专业
- 高级
- 能快速让招聘方理解
- 有一点 Editorial 感，但不能牺牲信息传达

例如：
“关于我”
“项目作品”
“AI实验室”
“建模渲染”
“联系方式”
优先于：
“策展之物”“关于主体”“视觉诗学”等过度文学化标题。

网站整体建议以中文为主，必要时可以保留少量英文作为辅助标签，例如：
ABOUT / SELECTED WORKS / AI LAB / 3D，但不能让主要信息全部英文。

## 7. 图片使用策略

用户现在需要更新图片，因此后续应该把网站结构和图片内容分开处理。

建议流程：
第一阶段：先把视觉风格和版式确定。
第二阶段：确定中文文案。
第三阶段：把用户真实项目图片逐个替换。
第四阶段：再优化图片裁切、比例、动效和页面节奏。

图片原则：
- 不要让 AI 随意编造用户没有做过的商业作品。
- 项目封面优先使用用户最强的真实作品。
- 不要为了填页面而堆大量普通作品。
- 精选案例少而深，更多项目多而精简。
- Hero 可以使用最能代表个人审美的视觉，但最终最好来自用户自己的作品。
- AI实验室可以展示过程，但要强调设计判断和工作流。

## 8. 动效原则

高级感来自克制，而不是堆特效。

推荐：
- 页面进入淡入
- 图片轻微上移
- 轻微 scale 过渡，例如 1.03 → 1
- 3～5px 级别的微弱视差
- 项目之间有自然的滚动节奏
- hover 时轻微放大 / 位移
- 页面切换可以有短暂淡入

避免：
- 大幅 3D 鼠标跟随
- 过度弹跳
- 炫酷粒子
- 霓虹科技特效
- 大量玻璃拟态动画
- 影响阅读和作品观看的动画

## 9. AI Studio 工作方式

用户是设计师，不是程序员，希望可以一步一步用 AI Studio 完成。

当前建议：
- 先用 Google AI Studio 确定创意、风格、页面结构。
- 不要现在就引入 Codex。
- Codex 更适合网站视觉方向确定后，用于后期代码维护、动画优化、响应式、Bug 修复、性能优化。
- AI Studio 当前阶段应作为主要“设计 + 生成 + 迭代”工具。

迭代原则：
一次只改一个维度，避免 AI Studio 一次性重写整个网站：
1. 风格
2. 页面结构
3. 中文文案
4. 图片
5. 动效
6. 响应式 / 代码细节

## 10. 后续 Agent 应该如何协助

如果用户把这个文件交给 Agent，Agent 应默认理解：
- 这是一个个人 AI视觉 / 电商 / 品牌视觉设计师作品集。
- 目标不是炫技，而是展示商业设计能力 + AI能力 + 3D能力。
- 风格基准是 Luxury Editorial + 黑色极简 + 磨砂 / 哑光质感。
- 页面顺序固定为：首页 → 关于我 → 项目作品 → AI实验室 → 建模渲染 → 联系方式。
- 关于我需要较大、接近 1920×1080 的完整视觉板块。
- 项目作品是网站核心，需要大量真实作品图片和完整 Case Study。
- 用户非常在意图片排版和视觉高级感。
- 用户不喜欢粉色弥散、过度 AI 物体、过度科技感、建筑事务所感、空洞的高级文案。
- 不要擅自改变已经确认的信息架构。
- 不要虚构用户项目、品牌成果、项目数据。
- 当用户提出“改风格”时优先调整视觉艺术指导，不要先改代码架构。
- 当用户提出“改文案”时不要顺便重做布局。
- 当用户提出“换图片”时保持图片位置、比例、动效逻辑，除非用户明确要求重新排版。

## 11. 当前阶段

当前网站处于初版 / 视觉探索阶段。

下一步推荐：
1. 在新的 AI Studio 项目中先建立 Luxury Editorial + 磨砂质感基准。
2. 确认首页视觉和 About 1920×1080 板块。
3. 确认六段信息架构。
4. 再修改中文文案。
5. 最后逐个替换真实作品图片。
6. 作品图片全部确定后，再用 Codex 做工程层面的精修。
