## 02｜我的求职定位

目标岗位： - 美妆电商视觉设计 - 电商视觉设计 - 其他品牌 /
电商视觉设计岗位

目前希望形成的个人定位：

**AI视觉设计师 / AI电商视觉设计师**

更准确的能力组合是：

**品牌视觉 × 电商设计 × 3D渲染 × AI创意生产**

英文可使用：

**AI VISUAL DESIGNER**

定位不是"纯 AI 生成师"，也不是单纯"美工"。

希望通过作品集体现： 1. 有商业电商视觉设计能力； 2.
能做高端美妆品牌视觉； 3. 有 3D 建模、渲染和动态视觉能力； 4. 能使用 AI
辅助创意生产和视觉执行； 5. 能把
AI、3D、平面设计整合成完整视觉解决方案。

目前作品主要分为以下几类：

### A. 高端美妆 / 电商平面设计

主要包括： - 品专 Banner - 电商详情页 - 电商主图 - KV / KV 延展 -

作品整体以真实商业项目为主，而不是纯个人概念练习。

### B. 3D 建模 / 渲染

包括： - 电子产品 3D 建模 - 产品静帧渲染 - 动态渲染动画 - 3D
辅助电商视觉 - 产品材质、灯光、镜头等视觉表达

这一部分希望体现"视觉设计 + 三维能力"，而不是单独做成工业设计作品集。

### C. AI 创意生产

包括： - AI 视觉生成 - AI 辅助电商视觉生产 - LoRA 模型训练 - LoRA
模型相关实验 - AI 工作流探索 - AI 生成资产在商业视觉中的应用

希望呈现的是： **AI 是设计生产力，而不是作品本身。**

不要把作品集做成"AI 图片画廊"。

## 04｜作品集整体视觉方向

目前已经基本确定喜欢的方向：

### 核心关键词

**高端 / 黑色 / 克制 / 编辑感 / 极简 / 科技感 / 美妆感 / 弥散光 /
磨砂玻璃 / 半透明材质 / 柔和光晕 / 精致排版**

整体参考：

**Monopo 风格 + 高端美妆品牌视觉 + 现代数字设计**

视觉比例大致希望： - 高级美妆感：40% - 极简 / Apple 式克制感：30% -
Monopo / 数字体验感：30%

不是纯科技风。

也不是传统"设计师作品集模板风"。

## 06｜目前最认可的封面方向

曾经尝试过： - 机器人 + 花朵 - 机械 + 花朵 - 鹦鹉螺 + 机械 -
大面积花朵 - 粉紫弥散光 - 蓝紫粉渐变 - 黑金光效 - 纯弥散光底图 -
大量玻璃卡片

经过多次讨论后，目前认为：

**不要让"机器人 / 花朵 / 机械"等概念元素成为封面的绝对主体。**

原因： - 容易显得像 AI 艺术作品集； -
容易抢掉作品集本身的视觉设计能力； -
与"美妆电商设计师"的职业定位不够直接； - 容易变得复杂、概念化； -
未来作品内容是商业电商设计，封面过于科幻会造成内容与封面割裂。

## 07｜目前最喜欢的一张参考封面

用户提供过一张黑色背景 + 大型花朵的作品集封面参考。

主要特征： - 整体黑色； - 中央 /
偏中部有一朵大型、具有高级摄影质感的花； - 花朵带有暗金 / 棕金 /
暖色调； - 标题"PORTFOLIO"使用非常大的粗体； - 文案非常少； -
整体具有高级美妆品牌广告的感觉； - 黑色背景提供强烈留白； -
主体视觉简单直接。

这张参考比"机器人 + 花""机械 + 花"等方案更适合作为美妆电商作品集的方向。

------------------------------------------------------------------------

## 08｜希望在上述参考上加入的视觉语言

在黑色 + 花朵的基础上，希望增加：

### ① 弥散光

要求： - 非粉色为主； - 不要廉价 RGB； - 不要明显赛博朋克； -
不要大面积彩色渐变； - 光应该像摄影棚 / 高端品牌广告中的环境光； -
可以有暖金、香槟金、暗红、极少量冷灰光； - 光线柔和、扩散、低对比； -
作为背景氛围，而不是视觉主体。

### ② 磨砂 / Frosted Glass

希望有： - 半透明磨砂玻璃 - 低透明度玻璃层 - 柔和边缘 - 轻微高光 -
轻微折射 - 柔和模糊 - 低存在感

重点： **磨砂玻璃只是视觉系统，不应该变成大量装饰卡片。**

## 09｜当前封面最重要的构图原则

封面应该让人第一眼感觉：

> "这是一个懂品牌视觉和电商设计的人，而不是一个只会生成 AI 图片的人。"

因此：

### 主体占比

-   核心视觉主体建议控制在整个画面约 30%～50%；
-   不要让巨大花朵 / 巨大物体铺满整个画面；
-   大量留白；
-   给标题和个人信息留下清晰区域。

### 文字

建议： - PORTFOLIO / OURUI 等大标题； - AI VISUAL DESIGNER； -
中文定位： **品牌视觉 × 电商设计 × AI创意生产** - 可以加入年份： **2024
--- 2026** - 可以加入少量能力标签。

不要让 AI 直接生成大量中文正文。 最终文字建议在 Photoshop / Figma /
InDesign 中排版。

### 构图

倾向： - 左侧文字 + 右侧 / 中右侧视觉； 或 - 大面积留白 +
中央偏右的抽象主体； - 非对称构图； - 编辑设计感； - 有一定空间层次。

## 10｜色彩方案

### 方案 A：黑金

主色： - 深黑 - 炭黑 - 暗灰

辅助： - 香槟金 - 暖金 - 暗琥珀 - 少量暖白

特点： - 高端 - 美妆 - 商业 - 奢华但克制

避免： - 大面积亮金 - 金色渐变过于俗气 - 金色装饰线过多

### 方案 B：黑色 + 冷暖弥散光

主色： - 黑 - 深灰 - 蓝黑

光色： - 暗红 - 少量酒红 - 暖白 - 少量冷蓝 / 冷灰

要求： - 红色 / 粉色如果出现，只能作为非常弱的环境光； -
不要粉紫赛博朋克； - 不要大面积霓虹。

## 11｜关于"机械 + 花朵"的思路

曾经考虑用：

**机械 × 花朵**

作为"AI + 设计 + 美学"的象征。

这个概念仍然可以作为后续视觉语言，但不建议直接使用一个明显的机器人。

更推荐： - 花瓣中出现非常微妙的机械结构； - 花瓣与金属结构自然融合； -
有机曲线与精密结构结合； - 金属 / 陶瓷 / 玻璃 / 磨砂材质； -
不出现完整机器人； - 不出现明显的人形机械； - 不做科幻电影海报。

目标是：

**有机美学 × 人工制造**

而不是：

**机器人 + 花 = AI**

如果未来需要 AI Lab 页面，可以把这种视觉语言用于 AI 实验室模块。

## 12｜封面底图目前更推荐的方向

最推荐：

**黑色极简背景 + 非常克制的弥散光 + 少量磨砂玻璃层 +
一个低存在感的高级抽象视觉主体。**

主体可以是： - 抽象花朵； - 微妙的花瓣结构； - 金属 /
玻璃与花朵的局部融合； - 非具象的有机机械结构； - 极简几何玻璃层。

不要： - 巨型机器人； - 巨型花朵占满画面； - 大量漂浮卡片； - 大量 UI
元素； - 赛博朋克； - 粉紫霓虹； - 大量粒子； - 科幻 HUD； -
复杂科技装饰。

## 13｜目前参考图的视觉判断

曾生成 / 讨论过一张： - 黑色背景； - 大花； - 大号 PORTFOLIO； -
金色光； - 磨砂玻璃矩形； - 少量环境光。

这个方向基本成立。

但需要继续优化：

### 当前优点

-   黑色与美妆行业匹配；
-   大字号很有编辑感；
-   黑金容易产生高级品牌感；
-   磨砂玻璃可以作为统一视觉系统；
-   适合未来网站延展。

### 当前问题

-   花朵可能仍然太大；
-   玻璃框容易成为装饰模板；
-   AI 生成文字不稳定；
-   光效如果太强会抢主体；
-   如果金色太多，会变成传统"奢华风"。

所以后续 AI 出图应优先生成：

**纯底图 / 视觉素材，不生成文字。**

文字最终由 Photoshop 完成。

## 15｜作品集叙事逻辑

不要把作品集做成：

> "我会 PS → 我会 3D → 我会 AI → 我会 LoRA"

更好的叙事是：

> **品牌理解 → 视觉概念 → 电商表达 → 3D / AI辅助生产 → 商业落地**

最终希望招聘方看到的是：

**一个具备商业视觉基础，同时拥有 AI + 3D 新生产能力的电商视觉设计师。**

## 16｜AI生成图片的使用原则

主要工具： - Nano Banana - Photoshop - AI 图像生成工具 - LoRA

AI 生成主要负责： - 氛围 - 背景 - 材质 - 光影 - 创意视觉资产

Photoshop / 设计软件负责： - 产品替换 - 排版 - 字体 - 信息层级 -
电商尺寸适配 - 最终合成 - 商业规范

因此生成图片时应该优先要求：

**clean background / negative space / controlled composition / no text /
no logo / no product / editable visual area**

## 20｜后续 Agent 最重要的判断标准

每当需要决定一个视觉方案是否适合，都问：

### Q1

它看起来像"电商 / 品牌视觉设计师"，还是像"AI艺术家"？

### Q2

它是否符合高端美妆行业？

### Q3

它是否足够克制？

### Q4

它是否给真正的作品留出了主角位置？

### Q5

这个视觉语言能不能从 PDF 延展到网站？

如果其中多数答案是否定的，应主动提出优化，而不是机械执行。
